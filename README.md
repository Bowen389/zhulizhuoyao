## Top3 规则

1. **T 日盘后初筛**。沪深主板，排除 ST。用前复权日线，取最近 10 根有效 K 线的最高价 H10 和最低价 L10。红线为 `SMA(200*(C-L10)/(H10-L10)-105,5,1)+15`，绿线为 `SMA(200*(H10-C)/(H10-L10)-125,5,1)+15`。昨日红线不高于绿线，今日红线高于绿线。10 日高低区间宽度为零时跳过依赖该日的金叉判定。
2. **量能底座**。估算流通市值严格低于 75 亿元，换手率在 [5%, 15%)，成交量在 [30 万, 80 万) 手。估算流通市值为未复权收盘价乘成交股数再除以换手率小数。
3. **T+1 开盘确认**。用同口径复权价计算开盘价除以上一收盘价减一。优先选择缺口在 [−2%, −1%) 的低开档，其次由 [0%, +3%) 补足。同档按缺口从小到大，再按代码升序。每天最多三只，有几只合格就取几只。
4. **组合口径**。Top3 六仓版本单笔预算为前一日净值的六分之一，按整手和可用现金约束。T+1 开盘买入，T+2 收盘卖出。停牌或估算收盘跌停则顺延。候选名单只反映规则筛选结果。
5. **费用口径**。原回测费用假设为买卖各 0.015%，完整复算应另在卖出端计入 0.05% 印花税。竞价后真实成交价仍需逐笔行情验证。
